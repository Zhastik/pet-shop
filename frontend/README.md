# FORMA — магазин очков

Фронтенд доступен по адресу http://localhost:8000/shop/ после запуска существующего FastAPI-приложения:

    uvicorn app.main:app --host 0.0.0.0 --port 8000

Нужны зависимости requirements.txt, настроенная PostgreSQL и применённые миграции. Каталог использует настоящие товары API: добавьте категории и товары через /docs под аккаунтом продавца. При пустой или недоступной базе интерфейс показывает соответствующее состояние.

Реализованы поиск, категории, ограничение цены, наличие, пагинация, просмотр товара, регистрация покупателя, вход, корзина с изменением количества, оформление заказа и история заказов. Токен хранится в sessionStorage до закрытия вкладки; при истечении требуется повторный вход. Суммы API в формате Decimal обрабатываются как строки чисел. Оплата и доставка не добавлены: таких маршрутов в API нет.

Статика размещена на /shop/, API и /media/ продолжают работать по существующим адресам. Внешние сборщики и зависимости для фронтенда не нужны.

## Запуск через Docker

Запустите Docker Desktop, затем из корня проекта:

    docker compose up -d --build

Магазин: http://localhost:8000/shop/
Документация API: http://localhost:8000/docs

В .env должен быть SECRET_KEY (случайная длинная строка). Compose передаёт его в контейнер, сам файл .env в образ не копируется.

PostgreSQL проходит проверку готовности, затем web применяет миграции, добавляет стартовый товар и запускает сервер. FORMA Everyday — 4990 ₽, 25 штук, категория «Солнцезащитные очки». Повторный запуск не восстанавливает проданный остаток и не меняет цену. Служебный продавец неактивен и имеет случайный пароль.

    docker compose logs -f web
    docker compose down

База сохраняется в томе postgres_data, изображения — в папке media. Не удаляйте том, если хотите сохранить заказы и пользователей.
